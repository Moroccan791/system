# Font sources and licenses

The shipped preview/render fonts are open-licensed files. The style-card
catalogue is vibe-matched to editorial references, but uses only these
licensed files—not fonts copied from paid tools. Before adding a family, verify
its official license and add the full license text here beside the font files.

| Archivo / Archivo Black | `@fontsource/archivo-black`, Archivo family package | `OFL-Archivo.txt`, `OFL-ArchivoBlack.txt` — SIL OFL 1.1 |

Role specimens choose the actual bundled style cut (for example, Newsreader
Book Italic or Outfit Semibold). The user approves fonts and font colours on
the per-video specimen card before production. Do not silently substitute a
font, inherit another video's accent, or use an unlicensed lookalike.
