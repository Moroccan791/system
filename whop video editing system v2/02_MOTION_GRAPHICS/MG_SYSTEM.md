# 02 — MOTION GRAPHICS (Not CapCut Slop)

## Why yours look cheap
- Star explosions, fire swoosh on every transition → template spam, viewer knows it's free pack
- No brand palette → neon blue/yellow on everything, no cohesion
- Bouncy ease (overshoot) → looks like TikTok kid, not pro

## Pro MG System (4 Elements Only)

### 1. Brand Palette (Lock this, use everywhere)
Picked from your butterfly/Pi art + Sartain refs (muted, professional, not neon):
```
Primary Black:  #0A0A0A (background)
Paper White:    #F5F1E8 (captions body)
Signal Yellow:  #FFD60A (emphasis, hook, CTA)
Muted Purple:   #6B5B95 (lower thirds bg)
Signal Cyan:    #00D4FF (data/tech viz ONLY, never on text)
```

**Rule:** 90% black/white, 10% yellow/cyan. Never rainbow.

### 2. Lower Thirds (Sartain podcast style)
Your refs `Being-Called-A-Player-Isn't-A-Bad-Thing` uses this — we systematize it:

```
Structure: [LOGO DOT 12px] Name | Title in 2 lines, muted purple bar
Font: Inter Bold 28pt white + Inter Regular 18pt 70% white below
Animation: Slide from left 12f ease-out, hold, fade out 8f
Sound: Soft pop (not whoosh)
Duration: 2.5s max, then out
```

**Templates:** 
- `LT_GUEST.mogrt` — for podcast guests (Sartain)
- `LT_STAT.mogrt` — for "80% of men..." stats (big number left, label right)

### 3. Callouts & Arrows (For tutorials / breakdowns)
Your `podcast tutorial` shows minimal text animation — we standardize:

```
Callout: White stroke 3px box, 0% fill, corner radius 8px, yellow dot anchor
Animation: Draw-on 12f (trim path), not pop
Font: JetBrains Mono 16pt yellow inside
Sound: Click, not swoosh
Use: Max 1 per 8 seconds. If you use more, you're slop.
```

### 4. End Card / CTA (WHOP funnel)
```
Frame: Black, centered logo, thin yellow line above CTA
Text: "Full breakdown on WHOP → link in bio" (Inter 22pt white) + arrow →
Animation: Fade in 15f, hold, logo pulse 103% over 2s (same as faceless art zoom)
Never: Spinning subscribe button, fire particles
```

### 5. Logo Sting (2 seconds, use on every video start OR end, not both)
```
0.0s: Logo from 98% → 100% scale + opacity 0→100 in 10f
0.3s: Hold + subtle grain
1.0s: Thin yellow underline draws left→right in 12f
1.8s: Out fade 8f
Sound: Low sub-hit + subtle grain texture
```

## Speed Rule (Fixes slow)
- All MG are **MOGRT / CapCut template** — drag, change text, done. No manual keyframing.
- No custom animation per video. If you keyframe something new every time, you're doing it wrong.

## What to Delete
- Delete CapCut "Motion" free pack favorites — all of them. They = AI slop signal.
- Keep 4 MG only: Lower Third, Callout, End Card, Logo Sting. Everything else is a hard cut.
