# campaign_demo (synthetic)

Generated by `python -m clipper samples`.

`references/reference_01.mp4` was rendered with a *known* style:

- 3 shots of 2s each, hard cuts at [2.0, 4.0]
- a 1.13x punch-in over 0.3s at each cut
- captions: Montserrat 104px, upper case, #FFFFFF with a #FFE14D karaoke highlight,
  centred at cy=0.72, 3 words per cue

So `python -m clipper style campaign_demo` can be checked against the list above.

`raw/raw_01.mp4` stands in for the creator's long-form upload (a tone: real
speech recognition needs real speech, so use a real file to test captions).
